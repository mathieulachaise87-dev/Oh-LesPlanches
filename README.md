# Oh! Les Planches — site du festival

Site web statique (un seul fichier `index.html`) du festival "Oh! Les Planches", Espace Mazelle & Auditorium de Rilhac-Rancon, 4–8 novembre 2026.

## Mise à jour du site

1. Récupérer la nouvelle version du fichier `index.html`.
2. Sur GitHub, ouvrir le dépôt, cliquer sur `index.html`, puis sur l'icône crayon (Edit) ou "Add file → Upload files" pour le remplacer par la nouvelle version.
3. Valider ("Commit changes").
4. Netlify redéploie automatiquement le site en 1 à 2 minutes — rien d'autre à faire.
